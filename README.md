# claude-code-harness-idea

Un "idea file" para armar un harness de Claude Code en cualquier repo: verify en un comando, wiki para LLM, agentes con modelo por rol, hooks, worktrees en paralelo con base propia y un proceso autor + revisor.

Cómo usarlo: copiá [IDEA.md](IDEA.md) a tu repo y decile a tu agente "Leé IDEA.md y armá este harness en mi repo". En [examples/](examples/) hay archivos de referencia.
